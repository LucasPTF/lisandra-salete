# Lisandra e Salete — Diagnóstico da Mulher que Dá Conta de Tudo

Conversão estática dos três ângulos exportados do Elementor.

- `/a1/` — ângulo “Você dá conta de tudo”
- `/a2/` — ângulo “Dar conta de tudo nem sempre é força”
- `/a3/` — ângulo “Em 4 horas, você vai entender”

Os arquivos originais ficam preservados em `source-json/`. As páginas atuais são geradas por `tools/generate-pages.cjs`, validadas e preparadas em `dist/` para publicação.
